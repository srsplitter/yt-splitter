어떤 형태의 유튜브 링크든 붙여넣으면 시작 시간별 링크로 쪼개줍니다. API 키 불필요.

⚠ 영상 길이를 자동으로 가져오지 못했습니다. 길이를 직접 입력해 주세요.

생성된 링크

입장 BGM

한국 시간 자정(00:00) 기준으로, 하루 중 치지직 채팅에 처음으로 직접 채팅을 입력하면 저장해둔 노래 명령어가 2초 뒤 자동 전송됩니다. 설정은 이 브라우저(확장)에 저장되는 개인 설정이에요.

⚠ 이 기능은 하단의 확장 프로그램을 설치해야 사용할 수 있어요. 설치 후 페이지를 새로고침해 주세요.

게임 명령어

한국 시간 자정(00:00) 후 첫 직접 채팅 때 자동 전송됩니다. 순서: 입장 BGM(있다면) → !일괄 룰렛 → !일괄 가챠권 → !배율 → !인벤 → !기록 · 각 1초 간격. 전송이 끝날 때까지 채팅창 키보드 입력은 잠시 잠깁니다. 이 브라우저(확장)에 저장되는 개인 설정이에요.

⚠ 이 기능은 하단의 확장 프로그램을 설치해야 사용할 수 있어요. 설치 후 페이지를 새로고침해 주세요.

치지직 완전 자동 전송

크롬 확장을 설치하면 링크마다 전송⚡ 버튼이 생겨, 클릭 한 번으로 치지직 채팅에 명령어가 자동 입력·전송됩니다. 설치하지 않아도 복사 방식은 그대로 쓸 수 있어요.

확장 프로그램 다운하기 ⬇
  1. 위 버튼으로 받은 extension.zip의 압축을 풀어주세요.
  2. 크롬 주소창에 chrome://extensions 입력 → 우측 상단 개발자 모드 켜기.
  3. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 압축 푼 extension 폴더 선택.
  4. 이 페이지를 새로고침하면 전송⚡ 버튼이 나타납니다.

※ 크롬에 네이버 로그인이 되어 있고, 치지직 방송 탭(또는 "채팅창 열기"로 띄운 팝업)이 열려 있어야 전송됩니다.
