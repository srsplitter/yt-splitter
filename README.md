# 유튜브 타임스탬프 분할기

유튜브 링크를 넣으면 시작 시간별(기본 100초 간격) `!sr` 노래신청 명령어로 쪼개주는 도구입니다.

**사용하기:** https://srsplitter.github.io/yt-splitter/

- 유튜브 링크(watch / youtu.be 공유 / shorts / embed 전부 가능)를 붙여넣고 "링크 쪼개기"를 누르면 끝.
- 치지직 방송 링크를 넣으면 "채팅창 열기"로 채팅 전용 팝업을 띄울 수 있고, 복사할 때마다 그 창이 앞으로 옵니다.

## 완전 자동 전송 (선택 — 크롬 확장 설치)

버튼 한 번으로 치지직 채팅에 명령어가 **자동 입력·전송**되게 하려면 크롬 확장을 설치하세요.
설치한 사람에게만 분할기에 **전송⚡** 버튼이 나타납니다. (미설치여도 복사 방식은 그대로 사용 가능)

### 설치 방법 (1분)

1. 이 저장소를 ZIP으로 다운로드: [main.zip](https://github.com/srsplitter/yt-splitter/archive/refs/heads/main.zip)
2. 압축을 풀고 `extension` 폴더 위치를 기억해두세요.
3. 크롬 주소창에 `chrome://extensions` 입력 → 우측 상단 **개발자 모드** 켜기.
4. **"압축해제된 확장 프로그램을 로드합니다"** 클릭 → 풀어둔 `extension` 폴더 선택.
5. 끝. 분할기 페이지를 새로고침하면 전송⚡ 버튼이 보입니다.

### 사용 조건

- 크롬(또는 엣지 등 크로미움 브라우저)에서 **네이버 로그인이 된 상태**여야 채팅 입력이 가능합니다.
- 치지직 방송 탭(또는 "채팅창 열기"로 띄운 채팅 팝업)이 **열려 있어야** 전송됩니다.
- 이 확장은 `!sr https://youtu.be/영상ID?t=초` 형식의 메시지만 전송할 수 있게 잠겨 있습니다(임의 텍스트 전송 불가).

## 입장 BGM (확장 설치 시)

사이트의 **입장 BGM** 탭에서 유튜브 링크와 시작 시간을 저장해두면,
한국 시간 자정(00:00) 기준으로 하루 중 치지직 채팅에 **처음으로 직접 채팅을 입력**했을 때
저장된 노래 명령어가 2초 뒤 자동으로 전송됩니다.

**게임 명령어** 탭에서는 `!일괄 룰렛` `!일괄 가챠권` `!배율` `!인벤` `!기록`을 각각 켜둘 수 있고,
같은 타이밍에 입장 BGM(있다면) → 룰렛 → 가챠권 → 배율 → 인벤 → 기록 순서로 1초 간격 자동 전송됩니다.
전송이 모두 끝날 때까지 채팅창의 키보드 입력은 잠시 잠깁니다(명령어와 채팅이 섞이는 것 방지).

- 설정은 각자의 브라우저(확장 저장소)에 저장되는 개인 설정입니다.
- 하루에 한 번만 전송되며, 자정이 지나면 다시 활성화됩니다.
- 도구가 보낸 자동 전송은 "직접 채팅"으로 치지 않습니다 (키보드로 직접 친 채팅만 인정).

### 문제 해결

- **전송⚡ 버튼이 안 보여요** → 분할기 페이지 새로고침. 그래도 없으면 `chrome://extensions`에서 확장이 켜져 있는지 확인.
- **"치지직 탭과 연결 실패"** → 치지직 탭을 새로고침한 뒤 다시 시도.
- **"입력창을 못 찾았어요"** → 치지직 탭에서 네이버 로그인이 되어 있는지, 방송이 진행 중인지 확인.
